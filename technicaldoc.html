Introduction

Document Purpose

This technical document provides a comprehensive reference for developers, auditors, and system administrators responsible for maintaining and extending the AuditX application.

1.1 Product Overview

AuditX is a Windows desktop application developed in VB.NET (.NET Framework 4.8) designed to automate IT General Controls (ITGC) auditing for SAP ERP systems. The application provides:

  • Automated SAP GUI scripting for 18 ITGC control procedures
  • RFC-based user inactivity analysis via SAP .NET Connector (NCo)
  • Automated evidence collection with screenshot capture and Word report generation
  • Centralized configuration management with encrypted credential storage
  • Multi-system analysis for cross-system user comparison

1.2 Intended Audience

Developers

Extending controls, fixing bugs, adding features

IT Auditors

Understanding automated procedures and outputs

Sys Admins

Deployment, configuration, troubleshooting

Authentication & Security

3.1 Login Flow

AuditX uses a multi-layer authentication approach:

1
Windows Credential Dialog

CredUIPromptForCredentialsW displays native Windows login. Auto-fills current domain\username.

WindowsAuthHelper.Authenticate()
2
LogonUser API Validation

Win32 LogonUser validates credentials against Active Directory / local SAM.

LOGON32_LOGON_INTERACTIVE
3
License Certificate Check

Reads license.cert → AES-256 decrypt → Parse pipe-delimited fields → SHA256 signature verify.

CertificateManager.ValidateCertificate()
4
Firebase Expiry Validation

REST GET to Firebase RTDB verifies license exists and hasn't expired.

GET /licensed_users/{cid}.json
Access Granted

User data passed to Home form. LoginForm hidden, Home.Show() activates dashboard.

3.2 License Certificate Structure

license.cert (after AES decryption) 
CID|DOMAIN\Username|FullName|email@company.com|IssueDate|ExpiryDate|SHA256Signature

Fields:
  [0] CID            → Unique client/license identifier
  [1] WindowsID      → DOMAIN\Username (machine-bound)
  [2] Full Name      → Display name
  [3] Email          → Registered email
  [4] Issue Date     → Certificate creation date
  [5] Expiry Date    → Local expiry (secondary check)
  [6] Signature      → SHA256(CID + WindowsID + Expiry + FullName + Email + Key)

3.3 DPAPI Password Encryption

SAP RFC credentials are encrypted using Windows Data Protection API (DPAPI):

Encrypt (On Save)
ProtectedData.Protect(plainBytes, entropy, DataProtectionScope.CurrentUser)

Result stored as Base64 string in SQLite

Store
sap_systems.db → Password column (Base64)

Machine + user bound, cannot be copied

Decrypt (On Load)
ProtectedData.Unprotect(protectedBytes, entropy, CurrentUser)

Falls back to plain text if decryption fails

Security Note

DPAPI encryption is scoped to CurrentUser. Passwords encrypted on one machine/user cannot be decrypted on another. The entropy string "HouseKeeperEntropy_v1" adds an additional layer of application-specific protection.

SAP Integration

4.1 SAP GUI Scripting Engine

The application connects to SAP GUI via COM automation:

SAP GUI Connection Flow (ITGC_AUDIT.vb)
' 1. Launch SAP Logon
Process.Start(My.Settings.SAPLogonPath)
Thread.Sleep(3000)

' 2. Attach to SAP GUI (retry 3 times)
SapGuiAuto = GetObject("SAPGUI")
SAPApp = SapGuiAuto.GetScriptingEngine
SAPCon = SAPApp.OpenConnection(sapSystem)
session = SAPCon.Children(0)

' 3. Login
session.findById("wnd[0]/usr/txtRSYST-BNAME").Text = userID
session.findById("wnd[0]/usr/pwdRSYST-BCODE").Text = password
session.findById("wnd[0]/tbar[0]/btn[0]").press()

' 4. Verify login status
LoginStatus = session.findById("wnd[0]/sbar").Text
Screenshot Capture Modes
Foreground Mode
  • Maximizes SAP window
  • Simulates PrintScreen key
  • Captures from Clipboard
  • Includes taskbar & timestamp
Background Mode
  • Uses PrintWindow API
  • Falls back to BitBlt
  • Overlays timestamp text
  • No window focus required

Data Model

5.1 SQLite Database Schema

sap_systems.db → SapSystems Table
CREATE TABLE IF NOT EXISTS SapSystems (
    SystemName    TEXT NOT NULL PRIMARY KEY COLLATE NOCASE,
    AppServerHost TEXT NOT NULL,
    SystemNumber  TEXT NOT NULL,     -- Always 2 digits (e.g., "00")
    Client        TEXT NOT NULL,
    UserName      TEXT NOT NULL,
    Password      TEXT NOT NULL,     -- DPAPI encrypted (Base64)
    Language      TEXT NOT NULL,
    CreatedAt     TEXT NOT NULL DEFAULT (datetime('now')),
    UpdatedAt     TEXT NOT NULL DEFAULT (datetime('now'))
);
