Glossary

SAP & Technical Glossary

Hover over highlighted terms for instant definitions

SUIM

User Information System — Central transaction for analyzing SAP user authorizations and change documents.

RFC

Remote Function Call — SAP protocol for calling functions on remote systems via SAP NCo connector.

BAPI

Business Application Programming Interface — Standardized SAP functions (BAPI_USER_LOCK, BAPI_USER_CHANGE).

DPAPI

Data Protection API — Windows encryption scoped to CurrentUser. Used for SAP password storage.

NCo

SAP .NET Connector — Library (sapnco.dll) enabling .NET applications to communicate with SAP.

USR02

SAP table: username, creation date, validity, last login, user type, lock status, password change date.

SCC4

Client Administration — SAP transaction for managing client settings and change policies.

SE16

Data Browser — SAP transaction for viewing table contents (CDHDR, DEVACCESS, TRDIR).

RZ11

Profile Parameter Maintenance — View/change system parameters (password, scripting, audit).
